# Product Brief

Last updated: 2026-06-08

## Product concept

このアプリは、体重を記録するだけのアプリではなく、減量中の毎日の意思決定を軽くするための「減量コーチアプリ」として設計する。

最初のMVPでは、体重管理を中心にする。運動提案、食事提案、モチベーション機能は将来的な核だが、まずは体重の変化を正しく見せ、継続しやすい入力体験を作る。

## Target user

初期ユーザー像は以下とする。

- 30歳男性
- 身長167cm
- 体重80kg前後
- 平日1時間程度の運動時間を確保できる
- 運動習慣はあるが、体重がなかなか落ちない
- 使用できる運動メニューはランニング、サンドバッグ、30kgダンベル1つの筋トレ

## Core value

アプリの価値は以下の3つ。

1. 体重の変化を正しく理解できる
2. 今日やるべき行動がわかる
3. 体重が一時的に増えても、継続する理由を見失わない

## MVP scope

MVPの中心は体重管理とする。

MVPに含めるもの。

- 体重記録
- 体重グラフ
- 7日移動平均
- 目標体重と目標ペース
- トレンド判定
- モチベーションを維持するコーチコメント
- 入力継続を支えるリマインド/ストリーク表現

MVPでは含めないもの。

- 詳細な食事ログ
- レシピ提案
- 運動メニューの完全自動生成
- Apple Health / Google Fit連携
- AIチャットによる自由相談
- SNS共有

## Current next scope

2026-06-08時点の次スコープは、簡易な食事チェックを、食材DB、加工食品静的マスタ、バーコード、手入力補完、直近履歴を持つ食事実績へ置き換えること。

ただし、プロダクトの中心は引き続き「体重トレンドから今日の行動を決める減量コーチ」である。食事管理は、カロリーとPFCを細かく見せること自体ではなく、停滞時に食事量や脂質を具体的に調整できる状態を作るために追加する。

詳細は [nutrition_management_redesign.md](nutrition_management_redesign.md) と [food_master_refresh.md](food_master_refresh.md) に置く。

## Success metrics

体重そのものより、減量につながる行動を計測する。

- 7日間の体重入力率
- 30日継続率
- 7日平均体重の変化
- 週次レビュー閲覧率
- コーチコメント表示後の翌日入力率
- 入力にかかる時間

## Product principles

- 単日の体重増減でユーザーを不安にさせない。
- 主役は7日平均と2週間トレンドにする。
- 体重が落ちたことだけでなく、体重を記録したこと、行動を継続したことを評価する。
- 入力は10秒以内で終わる体験にする。
- 励ましは熱くしすぎず、具体的で次の行動に接続する。
